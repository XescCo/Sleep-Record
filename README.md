
# Suunto Data Project

## Data sources
- Activity (NDJSON monthly exports)
- Sleep (NDJSON monthly exports)
- Events (manual input)

## Goal
Analyze relationship between:
- Activity
- Sleep
- External events

- Analizar y rebajar la latencia del sueño

## Processing
- NDJSON files merged by type
- Aggregated daily level
- Joined with event calendar

## Tools
- Python (pandas)
- Tableau
